# 投早投小科创企业打分卡

## 目标

按资产模板 `assets/投早投小打分卡.xlsx` 的一级、二级、三级指标和评分标准，对目标企业进行证据化评分，生成可审计的 Excel 打分卡。每一项评分都必须同时给出：

- `得分`
- `情况描述`
- `信息来源`
- `证据等级/待核实状态`

不要只复述 BP。要把 BP、用户提供资料和互联网公开信息交叉验证后再评分。

## 输入

优先读取用户提供的材料：

- 企业 BP、融资材料、尽调报告、访谈纪要
- 财务报表、订单/客户清单、工商/股权资料、专利/奖项/资质文件
- 行业研报、竞品资料、估值对标材料
- 用户给出的投资方案条款、估值、轮次、拟投金额

如材料不足，仍可先生成打分卡，但必须把缺失项标为 `待核实`，不得编造。

## 工作流

1. 准备模板
   - 使用 `assets/投早投小打分卡.xlsx` 作为评分标准的唯一模板源。
   - 如需生成可填写工作簿，运行 `scripts/build_scorecard.py`，它会在原模板基础上新增 `信息来源`、`证据等级`、`依据摘录/链接`、`待核实事项` 等列。

2. 提取企业事实
   - 从 BP 和参考资料中抽取企业名称、主营业务、赛道、融资轮次、估值、投资方案、股东、团队、技术、客户订单、财务、现金储备、负债、专利、奖项、风险等事实。
   - 对所有关键数值保留时间口径，例如 `截至 2025 年末`、`2026Q1`、`本轮投后估值`。
   - 把事实按来源归类：`BP/公司材料`、`访谈/口述`、`公开网页`、`官方/监管/公告`、`第三方数据库/研报`、`模型估算`。

3. 做公开信息核验
   - 需要联网时，查询企业官网、工商公示/企查查类信息、专利局、裁判文书/信用中国、政府/协会/榜单官网、上市公司公告、招投标/采购、权威行业报告、新闻报道等。
   - 优先使用官方、监管、公告、客户披露、榜单主办方、专利局等一手或准一手来源。
   - 对 BP 与公开信息不一致的内容，以“差异说明 + 待核实问题”方式记录，不直接取高分。

4. 逐项评分
   - 严格沿用模板中每一行评分标准；不要自行新增满分项或改变权重。
   - 加分项、扣分项按模板处理，并留意一级指标满分上限。
   - 缺少证据时可以给保守分或 `待核实`，但要解释为什么不能确认。
   - 对需要计算的项，写明公式和口径，如现金储备率、订单覆盖度、资产负债率、营收 CAGR、估值相对可比公司倍数。

5. 标注来源
   - 每个非空 `得分` 与 `情况描述` 必须对应来源。
   - 来源格式优先用：`[S1] BP《文件名》p.12，披露截至 2026Q1 在手订单 1.2 亿元`。
   - 公开网页来源用：`[S2] 机构/网站，页面标题，发布日期或访问日期，URL`。
   - 口述信息用：`[S3] 管理层访谈，访谈日期，待第三方核验`。
   - 模型估算用：`[S4] 根据 BP 收入预测与可比公司 EV/Sales 中位数估算，方法见描述`。

6. 输出
   - 默认输出一个 `.xlsx` 打分卡。
   - 同时给出简短结论：总分、建议动作、主要加分来源、主要扣分/红旗、最关键待核实事项。
   - 若用户只要文字版，也按同一字段输出 Markdown 表格。

## 推荐输出结构

- `项目摘要`：企业名称、赛道、轮次、估值、拟投方案、综合结论
- `总分`：总分、各一级指标得分、重大扣分项
- `打分卡`：模板逐项填写
- `来源清单`：列出 S1/S2/S3 等完整来源
- `待核实清单`：按影响分值的重要性排序

## 资源

- `assets/投早投小打分卡.xlsx`：原始打分卡模板，评分标准以此为准。
- `scripts/build_scorecard.py`：从模板生成带来源列的项目打分卡，可用 JSON 批量填充。
- `references/scoring-guidance.md`：评分纪律、证据等级、来源标注、常见字段计算口径。
- `references/template-row-map.csv`：模板行号、指标层级、评分标准和指标注释索引；填写 JSON 时用其中的 `row` 精准定位。

## 使用脚本

生成空白可填写版本：

```bash
python3 scripts/build_scorecard.py --output /path/to/项目_投早投小打分卡.xlsx
```

用 JSON 填充：

```bash
python3 scripts/build_scorecard.py \
  --answers /path/to/answers.json \
  --output /path/to/项目_投早投小打分卡.xlsx
```

`answers.json` 示例：

```json
{
  "project_name": "示例科技",
  "as_of_date": "2026-05-25",
  "items": [
    {
      "row": 3,
      "score": 4,
      "description": "公司产品属于高端装备关键零部件，BP 披露已进入国产替代验证阶段；公开资料显示该环节存在进口依赖。",
      "sources": ["[S1] BP p.5", "[S2] 工信部公开文件，访问日期 2026-05-25"],
      "evidence_level": "B-交叉验证",
      "quote_or_link": "https://example.com",
      "to_verify": ""
    }
  ],
  "sources": [
    {"id": "S1", "type": "BP/公司材料", "citation": "《示例科技BP》，p.5，用户提供"},
    {"id": "S2", "type": "公开信息", "citation": "工信部公开文件，访问日期 2026-05-25，https://example.com"}
  ]
}
```

## 注意事项

- 不要把“赛道好”直接等同于企业可得高分；必须落到客户、订单、技术验证、现金流、估值和退出。
- 不要引用无法追溯的“据称”“行业人士表示”作为高置信来源。
- 不要因为 BP 缺失信息而自动给 0 分；区分“不满足标准”和“资料不足待核实”。
- 不要用过时数据覆盖最新公开信息；使用最新信息时写明日期。
