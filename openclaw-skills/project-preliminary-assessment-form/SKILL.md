# 项目前置研判信息表

## 目标

使用 `assets/附件2：项目前置研判信息表.xlsx` 作为唯一模板源，根据用户提供的企业 BP 和参考资料，结合互联网公开信息核验，生成一个可直接使用的项目前置研判信息表。

每个填写字段都必须能追溯来源。默认输出 Excel 工作簿，包含：

- 原模板中的 `项目前置研判信息表`
- 原模板中的 `Sheet2-主要财务数据表`
- 新增 `字段来源标注` 工作表
- 新增 `来源清单` 工作表

## 工作原则

- 不要只复述 BP，要把 BP 还原为可核验事实。
- 优先使用用户提供材料；关键事实可结合公开信息核验。
- 对每个字段标注来源编号、证据等级、依据摘录/链接和待核实事项。
- 对无法确认的信息写 `待核实`，不要编造。
- 对时间口径敏感的字段必须写明截至日期，如 `截至 2025 年末`、`2026Q1`、`本轮投前估值`。
- 财务数据必须注明单位、期间、是否审计、是否为管理报表或预测数。

## 工作流

1. 读取模板和字段索引
   - 模板：`assets/附件2：项目前置研判信息表.xlsx`
   - 字段索引：`references/field-map.csv`
   - 使用字段索引中的 `field_id`、`sheet`、`target_cell` 精准填入内容。

2. 提取企业事实
   - 基本信息：企业名称、性质、成立时间、地区、行业、科技属性、评级/授信、集团/实控人。
   - 业务方案：投资金额、方式、期限、持股比例、历史估值、本轮估值、募集资金用途、退出方式、分红/对赌/救济/治理安排。
   - 项目分析：行业规模、竞争格局、市场份额、产能、国产替代、技术成果、团队、客户验证、研发强度、股东结构、政府支持、经营财务、收益测算、风险舆情。
   - 打分情况：行业赛道、股东背景、标的公司、估值合理性、退出可行性、调整加分项、打分评价。
   - 推荐/研判意见：主要投资风险、项目核心优势、初步研判意见、方案优化意见。

3. 公开信息核验
   - 需要联网时，优先查官方、监管、公告、客户披露、专利/信用/司法平台、政府/协会/榜单官网、上市公司公告、招投标和权威行业报告。
   - 对 BP 与公开信息不一致的内容，写明差异并列为待核实，不直接采用对项目最有利的表述。
   - 对企业性质、实控人、股权结构、专利、资质、诉讼、融资、客户订单、政府支持、行业规模和竞品情况，尽量做交叉验证。

4. 填写 Excel
   - 先形成结构化 JSON，再运行 `scripts/build_preliminary_form.py` 生成工作簿。
   - 尽量保留模板原有版式，不在主表随意增删行列。
   - 来源标注写入单元格批注，并同步到 `字段来源标注` 工作表。

5. 输出结论
   - 交付 Excel 文件。
   - 同时给出简短说明：项目名称、初步研判意见、主要优势、主要风险、最关键待核实事项。

## 使用脚本

生成空白带来源标注工作表的版本：

```bash
python3 scripts/build_preliminary_form.py --output /path/to/项目_前置研判信息表.xlsx
```

用 JSON 填充：

```bash
python3 scripts/build_preliminary_form.py \
  --answers /path/to/answers.json \
  --output /path/to/项目_前置研判信息表.xlsx
```

`answers.json` 示例：

```json
{
  "project_name": "示例科技",
  "as_of_date": "2026-05-25",
  "fields": {
    "P001": {
      "value": "示例科技有限公司",
      "sources": ["[S1] BP p.3", "[S2] 国家企业信用信息公示系统，访问日期 2026-05-25"],
      "evidence_level": "B-交叉验证",
      "quote_or_link": "https://example.com",
      "to_verify": ""
    },
    "P023": {
      "value": "公司所在细分赛道 2023 年市场规模约 80 亿元，2026 年预计超过 150 亿元，需进一步确认统计口径。",
      "sources": ["[S3] 行业研究报告，2025-12"],

      "quote_or_link": "报告第 18 页",

    }

    {"id": "S3", "type": "第三方报告", "citation": "某行业研究报告，2025-12，p.18"}

```

## 资源

- `assets/附件2：项目前置研判信息表.xlsx`：原始 Excel 模板。
- `references/field-map.csv`：字段 ID、工作表、目标单元格、字段名和模板提示。
- `references/fill-guidance.md`：字段填写、来源标注、证据等级、公开信息核验和常用计算口径。
- `scripts/build_preliminary_form.py`：从模板生成带来源标注的项目前置研判信息表。

## 注意事项

- 如果用户同时要求“打分卡”，可联动使用 `early-small-tech-scorecard` 的结果填入本表“四、打分情况”。
- 如果用户没有提供财务报表，不要虚构 Sheet2 财务数据；写 `待补充财务报表`，并把它列入待核实。
- “行业政策”“行内评级”“行内授信”可能需要内部资料；没有内部口径时可写 `待行内系统确认`。
- 投资建议用 `积极推进`、`有条件推进`、`持续跟踪`、`暂不跟进` 等清晰口径，并说明前置条件。
