# 前置研判信息表填写指南

## 证据等级

| 等级 | 含义 | 适用场景 |
|---|---|---|
| A-官方/监管/公告 | 政府官网、监管披露、交易所公告、客户公告、专利局、法院/信用平台等 | 企业基础信息、资质、司法信用、上市公司客户、政策和榜单 |
| B-交叉验证 | BP/公司材料与至少一个独立来源一致 | 股权、融资、客户、技术、项目背景等 |
| C-公司材料 | 仅 BP、公司访谈、尽调附件或管理层口述支持 | 经营计划、客户管线、未来预算、条款意向 |
| D-第三方估算/模型 | 行业报告、券商研报、可比公司测算、IRR/估值模型 | 市场规模、估值对标、收益测算 |
| 待核实 | 材料不足、口径冲突、来源不可追溯 | 内部评级、授信、订单真实性、财务口径、诉讼舆情 |

## 来源格式

字段来源标注建议格式：

- `[S1] BP《文件名》p.12，披露截至 2026Q1 在手订单 1.2 亿元`
- `[S2] 国家企业信用信息公示系统，企业登记信息，访问日期 2026-05-25，URL`
- `[S3] 管理层访谈，2026-05-20，待第三方核验`
- `[S4] 根据上市可比公司 2026-05-25 收盘 EV/Sales 中位数测算，方法见字段描述`

每个已填写字段至少要有一个来源编号。若字段为分析判断，应同时列出事实来源和推理方法。

## 公开信息核验清单

- 工商/股权/实控人：国家企业信用信息公示系统、企查查/天眼查等数据库。
- 科技属性/资质：高新技术企业公示、专精特新名单、独角兽/小巨人/制造业单项冠军/链主企业名单。
- 专利/软著：国家知识产权局、中国版权保护中心。
- 司法/信用/舆情：裁判文书网、执行信息公开网、信用中国、监管处罚、主流媒体。
- 融资/投资人：36氪、IT 桔子、清科、投中、公司新闻稿、基金公告。
- 客户/订单：客户官网公告、上市公司公告、招投标、政府采购、供应商名录。
- 行业规模/格局：官方统计、协会数据、上市公司年报/招股书、券商研报、权威行业报告。
- 估值/退出：上市公司估值、同业融资、并购案例、IPO 审核状态、上市规则和板块适配。

## 常用计算口径

- 行业规模：优先使用细分赛道口径，注明年份、区域和统计口径。
- 市场份额：`标的企业相关收入 / 细分市场规模`，两个数必须期间一致。
- 产能利用率：`实际产量 / 设计产能`，注明统计期间。
- 研发强度：`研发支出 / 销售收入`，注明费用化/资本化口径。
- 资产负债率：`总负债 / 总资产`，注明报表日期。
- 收入 CAGR：用最近三年可比口径收入计算，区分历史数和预测数。
- IRR：注明投资金额、持股比例、退出年份、退出估值、分红/回购/补偿假设。
- 估值倍数：注明 PE/PB/PS/EV/Sales 等口径、可比公司样本、日期和是否剔除异常值。

## 字段填写纪律

- 标的企业名称、成立日期、地区、企业性质：优先用工商公示或公司章程/营业执照。
- 科技属性和科技类型：只写能对应证明文件或公示名单的称号；公司自称需标为待核实。
- 行内评级和授信：需要内部系统或用户材料；无资料时写 `待行内系统确认`。
- 主营业务：写贡献主要收入的产品/服务，不照搬营业执照经营范围。
- 项目背景：写项目来源、本轮领投/跟投/意向投资人、融资进度和关键交易背景。
- 估值情况：历史融资、本轮估值、估值方法、可比公司/交易和高低判断分开写。
- 募集资金用途：区分产线、研发、并购、流动资金、偿债等用途及金额占比。
- 退出方式及上市计划：写路径、时间表、当前阶段、障碍和替代退出安排。
- 对赌和救济措施：写触发条件、义务主体、补偿方式、担保或回购能力。
- 行业情况：必须写规模、增长、竞争格局、标的份额和国产替代/需求趋势。
- 技术及团队：区分专利数量、核心专利、奖项、客户验证、测试认证、团队履历。
- 经营及财务：区分历史数据、在手订单、预测数据；客户/供应商集中度要列明。
- 投资收益测算：不要只写结论，要写核心假设和敏感项。
- 主要风险：优先写会影响投资决策的风险，而不是泛泛的“市场竞争风险”。

## 待核实事项

待核实事项要能转化为尽调问题，例如：

- 请公司提供最近三年审计报告、最新一期管理报表及科目明细。
- 请公司提供前五大客户合同、订单、验收、回款及客户确认函。
- 请核验核心专利权属、有效期、许可/质押/诉讼情况。
- 请确认本轮投资人名单、投资金额、协议状态和退出投资人原因。
- 请提供上市路径、板块选择、中介初步意见和历史规范性问题清单。
